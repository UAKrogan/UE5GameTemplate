CORE SYSTEM ARCHITECTURE
========================

Base system interface
- File: Source/GameCore/Public/Interfaces/IAtlasSystem.h
- Type: pure C++ interface, not a UINTERFACE.
- Required functions:
  - Initialize(UAtlasGameInstanceSubsystem* Subsystem)
  - Shutdown()
  - GetSystemName() const
  - SupportsInterface(FName InterfaceName) const

Design rules documented in IAtlasSystem
- Systems are owned by UAtlasGameInstanceSubsystem.
- Systems initialize once per game session.
- Systems are pure logic containers.
- Systems should not directly depend on Actors.
- Systems should not own gameplay objects.
- Systems are controlled by subsystem lifecycle.

Central subsystem
- Class: UAtlasGameInstanceSubsystem
- File: Source/GameCore/Public/Subsystems/AtlasGameInstanceSubsystem.h
- Inherits: UGameInstanceSubsystem
- Responsibilities:
  - Own all runtime systems.
  - Register systems.
  - Initialize systems.
  - Shutdown systems.
  - Provide service-locator access to systems.

Subsystem lifecycle
- Initialize(FSubsystemCollectionBase&)
  - Super::Initialize(Collection)
  - log "AtlasGameInstanceSubsystem Initialize"
  - RegisterSystems()
  - InitializeSystems()
- Deinitialize()
  - log "AtlasGameInstanceSubsystem Deinitialize"
  - ShutdownSystems()
  - Super::Deinitialize()

System registration
- RegisterSystems() delegates to FAtlasSystemsRegistry::Register(this).
- Current registered systems:
  - FAtlasSaveSystem
  - FAtlasLoadSystem

System storage
- TMap<FName, TSharedPtr<IAtlasSystem>> Systems
- TArray<FName> SystemOrder

Lifecycle ordering
- Systems initialize in SystemOrder registration order.
- Systems shut down in reverse SystemOrder.
- Duplicate system names are rejected with a warning.

System lookup
- Template method: GetSystem<T>().
- Iterates through Systems.
- Calls Pair.Value->SupportsInterface(T::InterfaceName()).
- Returns StaticCastSharedPtr<T>(Pair.Value) when supported.
- Returns nullptr when missing.

Current lookup caveat
- Lookup is linear and fine for two systems.
- If many systems are added, consider an interface-name map/cache.

Systems registry

SAVE / LOAD ARCHITECTURE
========================

Current save/load model
- The current implementation uses binary world snapshots saved under Saved/SaveGames/.
- Actors opt in by having UAtlasSavableComponent.
- Optional state capture/restore is done by objects implementing IAtlasSavable through the UAtlasSavable UINTERFACE.
- Save collection runs on the game thread.
- Serialization and disk write run asynchronously on the thread pool.
- Load disk read and deserialization run asynchronously on the thread pool.
- Actor resolution/spawning and state restore run on the game thread.

Two related data models exist
- FAtlasSaveGameSnapshot:
  - Metadata plus typed key/value maps.
  - Still exposed through IAtlasSaveSystem/IAtlasLoadSystem.
  - PendingSnapshot can receive SetIntValue/SetFloatValue/etc.
  - BuildSnapshotForSave() populates metadata, but the current StartSaveRequest() path does not serialize this snapshot to disk.
- FAtlasWorldSnapshot:
  - Actual current persisted binary payload.
  - Contains actor snapshots and serialized data chunks.
  - Used by FAtlasSaveCollector, FAtlasBinaryWriter, FAtlasBinaryReader, FAtlasSaveSystem, and FAtlasLoadSystem.

Important implementation caveat
- The key/value FAtlasSaveGameSnapshot API and metadata API are not currently integrated into the binary world snapshot save file.
- FAtlasLoadSystem::LoadedSnapshot is reset and provides TryGetIntValue/TryGetFloatValue/etc., but current binary load populates LoadedWorldSnapshot, not LoadedSnapshot.
- Future implementation should either:
  - integrate FAtlasSaveGameSnapshot into the binary format, or
  - remove/replace the stale key/value snapshot API if world snapshots are the intended single model.

- SetRotatorValue(FName Key, const FRotator& Value)
- SetTransformValue(FName Key, const FTransform& Value)
- RemoveValue(FName Key)
- GetPendingSnapshot(FAtlasSaveGameSnapshot& OutSnapshot) const

Concrete type
- Class: FAtlasSaveSystem
- File: Source/GameCore/Public/Systems/Save/AtlasSaveSystem.h
- Implements:
  - IAtlasSaveSystem
  - TSharedFromThis<FAtlasSaveSystem>
- System name: "SaveSystem"
- SupportsInterface returns true only for IAtlasSaveSystem::InterfaceName().

State
- UAtlasGameInstanceSubsystem* OwningSubsystem
- FAtlasSaveGameSnapshot PendingSnapshot
- FAtlasSaveScheduler SaveScheduler
- bool bSaveInProgress
- bool bShuttingDown

Initialize()
- Stores OwningSubsystem.
- Resets PendingSnapshot.
- Clears in-progress/shutdown flags.
- Initializes FAtlasSaveScheduler with default config:
  - AutosaveIntervalSeconds = 300.0f
  - EventDebounceSeconds = 2.0f
  - bEnableTimerAutosave = true
- Scheduler callback calls ProcessNextSaveRequest().
- Logs "SaveSystem initialized".

Shutdown()
- Sets bShuttingDown.
- Shuts down scheduler.
- Resets PendingSnapshot.
- Clears OwningSubsystem.
- Logs "SaveSystem shutdown".

Default slot
- GetDefaultSlotName() returns:
  - "<ProjectName>_MainProfile" if FApp::GetProjectName() is non-empty.
  - "Atlas_MainProfile" otherwise.
- UserIndex is ignored for Atlas binary storage.
- Non-zero UserIndex logs warnings in SaveGameToSlot() and DoesSaveExist().

Manual save flow
1. SaveGame() calls RequestSave(GetDefaultSlotName()).
2. RequestSave() queues a manual save in FAtlasSaveScheduler.
3. Scheduler calls ProcessNextSaveRequest().
4. ProcessNextSaveRequest() exits if shutting down, already saving, or queue empty.
5. It pops the highest-priority request.
6. StartSaveRequest() resolves UWorld from OwningSubsystem->GetGameInstance()->GetWorld().
7. It collects an FAtlasWorldSnapshot on the game thread with FAtlasSaveCollector::CollectWorld(World).
8. It async serializes with FAtlasBinaryWriter::Serialize(WorldSnapshot, BinaryData).
9. It async writes with FAtlasFileStorage::SaveToSlot(Request.SlotName, BinaryData).
10. Completion returns to game thread and calls HandleSaveCompleted().
11. HandleSaveCompleted() logs success/failure, clears bSaveInProgress, and processes the next queued request.

Save failure behavior
- If world is null, StartSaveRequest logs an error and calls ProcessNextSaveRequest().
- Note: in the current code, bSaveInProgress is set after the null-world check, so this path does not leave bSaveInProgress stuck.
- Serialization/write failures are logged in HandleSaveCompleted().


SAVE SCHEDULER
==============

Class
- FAtlasSaveScheduler
- Files:
  - Source/GameCore/Public/Systems/Save/AtlasSaveScheduler.h
  - Source/GameCore/Private/Systems/Save/AtlasSaveScheduler.cpp

Responsibilities
- Timer-based autosaves.
- Event-driven saves with debounce.
- Manual/event/autosave priority queue.
- Queueing save requests without starting multiple saves directly.

Priority enum
- EAtlasSavePriority::Autosave = 0
- EAtlasSavePriority::Event = 1
- EAtlasSavePriority::Manual = 2

Request struct
- FAtlasScheduledSaveRequest:
  - FString SlotName
  - EAtlasSavePriority Priority
  - int32 AutosaveIndex
  - bool bAutosave
  - bool bEventSave

Default config
- AutosaveIntervalSeconds = 300.0f
- EventDebounceSeconds = 2.0f
- bEnableTimerAutosave = true

Ticker
- Uses FTSTicker::GetCoreTicker().
- Tick accumulates DeltaTime.
- When accumulator exceeds AutosaveIntervalSeconds, RequestAutosave() is called and accumulator resets.

Event save debounce
- Rejects event saves if:
  - last accepted event save was less than EventDebounceSeconds ago, or
  - an event save is already pending.

Priority selection
- PopNextRequest() scans PendingRequests and returns the request with the highest numeric priority.
- Manual saves outrank event saves, which outrank autosaves.


AUTOSAVE MANAGER
================

Class
- FAtlasAutosaveManager
- Files:
  - Source/GameCore/Public/Systems/Save/AtlasAutosaveManager.h
  - Source/GameCore/Private/Systems/Save/AtlasAutosaveManager.cpp

Responsibilities
- Thread-safe autosave ring slot reservation.
- Persistent tracking of the most recently reserved autosave index.

Slot layout
- Autosave_0
- Autosave_1
- Autosave_2
- Autosave_3
- Autosave_4

Constants
- AutosaveSlotCount = 5
- Index slot name = "AutosaveIndex"
- Autosave slot prefix = "Autosave"

Storage
- Saves the reserved autosave index through FAtlasFileStorage as Saved/SaveGames/AutosaveIndex.sav.
- Uses FMemoryWriter/FMemoryReader to store an int32.
- Uses FCriticalSection and FScopeLock.

Reservation flow
1. Lock critical section.
2. Load current reserved index, or use INDEX_NONE if missing/corrupt.
3. Compute next index with ring wrap.
4. Store next index before save starts.
5. Return "Autosave_<Index>" and the index.


SAVE COLLECTOR
==============

Class
- FAtlasSaveCollector
- Files:
  - Source/GameCore/Public/Systems/Save/AtlasSaveCollector.h
  - Source/GameCore/Private/Systems/Save/AtlasSaveCollector.cpp

Responsibilities
- Build an in-memory FAtlasWorldSnapshot from opt-in actors.
- Must run on the game thread.
- Does not write to disk.

Collection rules
- Iterates actors with TActorIterator<AActor>.
- Actor must be valid.
- Actor must have UAtlasSavableComponent.
- Savable component must have a valid ActorId.
- Snapshot stores:
  - ActorId
  - Actor class path
  - Actor transform
  - Data chunks captured from actor/components implementing UAtlasSavable.

Actor state capture
- If actor class implements UAtlasSavable, captures an "Actor" chunk.
- It iterates all actor components.
- If a component class implements UAtlasSavable, captures a component chunk.

Chunk naming
- Actor chunk:
  - "Actor"
- Component chunk:
  - "Component.<ComponentIndex>.<ComponentName>"

Capture method
- Casts UObject to IAtlasSavable.
- Uses FMemoryWriter and FAtlasSaveContext.
- Calls SaveContext.BeginChunk(ChunkName).
- Calls SavableObject->CaptureState(SaveContext).
- Calls SaveContext.EndChunk().
- Adds the resulting byte array as FAtlasDataChunk on the actor snapshot.

Important caveat
- Component restore depends on matching component index and component name.
- Reordering components or renaming components between save and load can break restore matching.

Concrete type
- Class: FAtlasLoadSystem
- File: Source/GameCore/Public/Systems/Load/AtlasLoadSystem.h
- Implements:
  - IAtlasLoadSystem
  - TSharedFromThis<FAtlasLoadSystem>
- System name: "LoadSystem"
- SupportsInterface returns true only for IAtlasLoadSystem::InterfaceName().

State
- UAtlasGameInstanceSubsystem* OwningSubsystem
- FAtlasSaveGameSnapshot LoadedSnapshot
- FAtlasWorldSnapshot LoadedWorldSnapshot
- bool bLoadInProgress
- bool bShuttingDown

Initialize()
- Stores OwningSubsystem.
- Resets LoadedSnapshot and LoadedWorldSnapshot.
- Clears in-progress/shutdown flags.
- Logs "LoadSystem initialized".

Shutdown()
- Sets bShuttingDown.
- Resets loaded snapshots.
- Clears OwningSubsystem.
- Logs "LoadSystem shutdown".

Default slot
- Same naming as save:
  - "<ProjectName>_MainProfile" or "Atlas_MainProfile".
- UserIndex is ignored for Atlas binary storage.

Load request flow
1. LoadGame() calls RequestLoad(GetDefaultSlotName()).
2. RequestLoad() checks game thread, shutdown, bLoadInProgress, and non-empty slot.
3. It sets bLoadInProgress and logs start.
4. It async loads bytes with FAtlasFileStorage::LoadFromSlot().
5. It async deserializes with FAtlasBinaryReader::Deserialize().
6. Completion returns to game thread and calls HandleSnapshotLoaded().
7. HandleSnapshotLoaded() clears bLoadInProgress.
8. If successful and not shutting down, stores LoadedWorldSnapshot.
9. Calls ApplyWorldSnapshot().

Restore flow
- ApplyWorldSnapshot():
  - Resolves UWorld from game instance.
  - Phase 1: ResolveActorsForSnapshot().
  - Phase 2: RestoreSnapshotState().

ResolveActorsForSnapshot()
- For each actor snapshot:
  - Skip invalid ActorId.
  - Try FindActorById() by scanning actors for UAtlasSavableComponent with matching ActorId.
  - If missing, SpawnActorFromSnapshot().
  - Ensure the resolved actor has UAtlasSavableComponent with the snapshot ActorId.
  - Set actor transform from snapshot.
  - Store actor in ActorsById map.

SpawnActorFromSnapshot()
- Loads actor UClass from ActorSnapshot.ClassPath using LoadObject<UClass>().
- Verifies class is an AActor subclass.
- Spawns with AlwaysSpawn collision handling.
- Adds/updates UAtlasSavableComponent with the saved ActorId.

RestoreSnapshotState()
- For each actor snapshot:
  - Finds resolved actor by ActorId.
  - RestoreActorState().
  - RestoreComponentState().

RestoreActorState()
- Requires actor class to implement UAtlasSavable.
- Looks for "Actor" chunk.
- Calls RestoreSavableObject().

RestoreComponentState()
- Iterates current actor components by index.
- Requires component class to implement UAtlasSavable.
- Builds "Component.<Index>.<Name>" chunk name.
- If chunk missing, logs warning.
- Calls RestoreSavableObject().

RestoreSavableObject()
- Casts UObject to IAtlasSavable.
- Uses FMemoryReader and FAtlasLoadContext.
- Begins expected chunk.
- Calls SavableObject->RestoreState(LoadContext).
- Ends chunk.

Load caveats
- It does not unload or destroy actors that exist in the current world but are absent from the snapshot.
- It can spawn actors whose class path exists in the save but is missing in the current map.
- Component matching is fragile because it uses component index and name.
- Current code logs but does not expose completion delegates/events.
- Only one load can run at a time.

Class

  - Source/GameCore/Private/Systems/Storage/AtlasFileStorage.cpp

Responsibilities
- Save raw binary data to Saved/SaveGames/.
- Load raw binary data from Saved/SaveGames/.
- Delete/check slots.
- Keep disk I/O separate from serialization.

Extensions
- SaveExtension = ".sav"

Paths

- Slot path:
  - Saved/SaveGames/<SanitizedSlotName>.sav
- Temp path:
  - Saved/SaveGames/<SanitizedSlotName>.tmp

Save behavior
- Rejects invalid/empty slot names.
- Rejects empty data.
- Ensures save directory exists.
- Writes to temp file first.
- Verifies temp file size matches data length.
- Deletes old slot file.
- Moves temp file to final slot file.
- Logs success/failure.

Load behavior
- Rejects invalid slot names.
- Requires file to exist.
- Rejects file sizes <= 0 or > 256 MiB.
- Loads file to array.
- Verifies loaded byte count equals file size.
- Logs success/failure.

Slot sanitization
- Trims whitespace.
- Replaces invalid filesystem chars with underscores.
- Replaces "/" and "\" with "_".
- Replaces ".." with "_".

SHORT HANDOFF SUMMARY
=====================

This is a UE 5.7 modular C++ project named Game using an Atlas-style architecture. The live modules are Game, GameActors, GameCore, GameUI, and GameUtils. Runtime starts through UAtlasGameInstance, which ensures UAtlasGameInstanceSubsystem exists. That subsystem registers FAtlasSaveSystem and FAtlasLoadSystem through FAtlasSystemsRegistry and controls their lifecycle deterministically.

GameCore now contains a real early save/load stack: savable actors opt in with UAtlasSavableComponent, actors/components can implement IAtlasSavable, FAtlasSaveCollector builds FAtlasWorldSnapshot data, FAtlasBinaryWriter/FAtlasBinaryReader serialize custom chunks, FAtlasFileStorage writes Saved/SaveGames/*.sav via temp files, FAtlasSaveScheduler handles manual/event/autosave priority queueing, and FAtlasAutosaveManager rotates five autosave slots. Load reads/deserializes asynchronously, then resolves or spawns actors and restores savable actor/component chunks on the game thread. Inventory and GAS save adapters exist, but the GAS adapter is approximate.

The main current caveat is that FAtlasSaveGameSnapshot/UAtlasSaveGame key-value metadata APIs still exist but are not integrated with the active binary world snapshot save path. Gameplay classes and UI are still stubs, no project map or real content exists, and README.md is behind the current source. Treat Source/GameCore as active and ignore stale Source/GameSystems migration residue unless the user explicitly asks to clean Git state.
